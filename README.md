# 落ちていく

**体験する：https://katomi95.github.io/ochite-iku/** （Quest 3 のブラウザで開くとVR、PCではプレビュー）

超高層ビル街の上空から、どこまでも落ち続ける VR 体験です。
スコアもクリアもありません。地面には、いつまでも着きません。

- 対象：Meta Quest 3 のブラウザ（Quest Browser）／WebXR `immersive-vr`
- PC ブラウザ用のプレビューモードあり
- Three.js r165 を `vendor/` に同梱（CDN 不要）。サーバー処理なしの静的サイト

## 起動方法

### GitHub Pages で公開する
このフォルダの中身をリポジトリのルートに置き、GitHub Pages（Settings → Pages → Deploy from a branch）を有効にするだけで動きます。
WebXR は **HTTPS 必須**です（GitHub Pages の `https://〜.github.io/…` は条件を満たします）。

### ローカルで確認する（PC）
`.js` を `text/javascript` で返す静的サーバーなら何でも動きます。例：

```bash
python -m http.server 8612
```

`http://localhost:8612/` を開いてください。

## Quest 3 での遊び方

1. Quest 3 のブラウザで公開 URL を開く
2. タイトル画面で「落下速度」と「視野制限」を選ぶ（既定：ゆっくり／視野制限 ON）
3. **座った状態で**「落下開始」を押す。VR に入るとビル街の上空にいます
4. 約4秒静止したあと、ゆっくり落ち始め、約9秒（はやいは約12秒）かけて一定速度になります。あとはずっと落ち続けます

| 操作 | 内容 |
| --- | --- |
| トリガー（左右どちらでも） | 一時停止／再開（数秒かけてなめらかに止まる） |
| A / X ボタン | 落下速度を切り替え（ゆっくり → ふつう → はやい） |
| B / Y ボタン | 視野制限（ビネット）の ON / OFF |
| グリップを 1.5 秒握り続ける | VR を終了してタイトルへ戻る |
| Meta（Oculus）ボタン | いつでもシステム側から終了できます |

Quest のメニューを開いて体験が隠れたときは、自動で一時停止します。
正面の向きは Quest 標準の「表示位置をリセット」（Meta ボタン長押し）で直せます。

## PC プレビューの操作

タイトル画面の「PCプレビューで見る」から。

| 操作 | 内容 |
| --- | --- |
| マウスドラッグ（タッチでも可） | 見回す |
| 矢印キー | 見回す（少しずつ） |
| Space | 一時停止／再開 |
| 1 / 2 / 3 | 落下速度 ゆっくり / ふつう / はやい |
| V | 視野制限 ON / OFF |
| Esc | タイトルへ戻る |

画面左上のボタンでも同じ操作ができます。描画処理は VR と完全に共通です。

## しくみ

- **プレイヤーは動かない**：カメラ（頭）は原点のまま。動くのは街のほうです。落下距離は JavaScript の倍精度で積算し、上限はありません。
- **ビル本体**：1棟＝1つの箱。下端は霧で見えない深さ（-4200m）に固定し、窓・外壁・設備階・LED 帯はシェーダーで描きます。落下距離の分だけ模様をずらすので、ジオメトリを動かさずに壁面が上へ流れます。模様は 16384m 周期で完全に繰り返し、GPU には周期で割った余りだけを渡すので、何時間落ちても精度が落ちず継ぎ目もありません。
- **屋上**：開始時に見下ろす屋上・設備・ヘリポート・航空障害灯は、落下とともに上へ去り、十分上で止めて非表示にします。
- **壁面の装飾**（室外機・配管・縦型ネオン看板・巨大広告・渡り廊下）：2000 個のインスタンスを使い回し。上端を越えたものだけを下端へ戻し、そのとき別のビル・別の種類に付け替えます。生成・破棄はしません。出入りする上下端では霧に溶かすので、出現・消滅は見えません。
- **風の筋**：プレイヤー周囲の 700 本の線。位置計算はすべて頂点シェーダー。
- **地面**：ありません。下方向は霧と「奈落の空色」に溶けていきます。
- **風切り音**：Web Audio でノイズを加工して合成（音声ファイルなし）。左右別ノイズ・3層。速度に応じて大きくなり、上限付きでなめらかに飽和します。

## VR 酔いへの配慮

- カメラシェイク・強制回転・視点切り替えは一切ありません。頭の動きはそのまま反映します。
- 落下速度は ゆっくり 7m/s ／ ふつう 30m/s ／ はやい 60m/s。
- 加速は最大 5m/s²（はやいは約12秒、それ以外は約9秒で一定速度）、減速（一時停止）は最大 8m/s² に制限し、加速度そのものもなめらかに立ち上がるようにしています。
- プレイヤーの周囲は半径 40m 以上ビルのない吹き抜けにしてあり、壁面が至近距離を高速で通過しません。
- ビネットは各目のビュー空間に直接描くので、頭の動きに遅れません。速度が上がると少しだけ強くなります。
- それでも VR 酔いには個人差があり、これらで防げるとは限りません。気分が悪くなったらすぐに一時停止するか、ヘッドセットを外してください。

## パフォーマンス上の注意点

- 1フレームの描画は **5 ドローコール**（ビル・屋上設備・壁面装飾・空・風の筋）＋ビネットと案内板。三角形は約3万。
- 影は使っていません。ライティングはシェーダー内の簡易計算のみ。
- ビルは手前から順に描くよう並べ替え済み（プレイヤーが水平移動しないため一度だけ）。Zテストで奥の描画を省けます。
- 遠くの窓は1画素より小さくなると平均色に切り替え、モアレとシェーダー負荷を抑えています。
- 毎フレームの CPU 処理は、装飾の付け替え判定（2000 回の比較）と数個の付け替えのみ。オブジェクト数・メモリは時間で増えません。
- Quest 側の固定フォビエイテッドレンダリングを有効化（`setFoveation(1)`）。
- 負荷が高いと感じた場合の調整箇所：`js/city.js` の `DECO_COUNT`、`_layout()` の `N`（街の広さ）、遠景の棟数（170）、`js/effects.js` の粒子数（700）。

## Quest 3 実機での確認項目

> 2026-10-09 時点で、PC ブラウザ（プレビュー）での動作のみ確認済み。Quest 3 実機では未確認です。

1. 公開 URL を開くとタイトルが表示され、「落下開始」が押せる状態になる（「VRで体験できます」と表示される）
2. 「落下開始」で VR に入り、ビル街の上空・屋上より上にいる。正面に操作説明が出て、数秒で消える
3. 約4秒後にゆっくり落ち始め、屋上を通り過ぎてビルの谷間へ入っていく
4. フレームレートが安定している（カクつき・ガクッとした止まりがない）。特に屋上を通過する前後と、見下ろしたとき
5. 見下ろすと壁面が奈落の霧へ続き、地面が見えない。見上げると空が小さく見える
6. 窓・看板・配管が上へ流れ、落下している感覚がある。窓の模様がチラチラしすぎない
7. 風切り音が速度とともに強くなり、一定速度で落ち着く。長く聞いて不快でない音量か
8. トリガーで数秒かけて止まり、「一時停止中」の板が出る。もう一度で再開する
9. A/X で速度、B/Y で視野制限が切り替わり、案内が出る
10. グリップ長押しでバーが伸び、1.5 秒で VR が終了してタイトルに戻る。途中で離すとキャンセルされる
11. 10分以上落ち続けても、建物が途切れない・表示が崩れない・重くならない
12. ビネット ON/OFF で周辺の暗さが変わる。左右の目で違和感がない
13. 頭を動かしても視点が勝手に揺れたり回ったりしない

## ファイル構成

```
index.html        タイトル画面・PCプレビューのボタン
style.css
js/main.js        起動、VR/PC の切り替え、コントローラー・マウス・キー入力
js/city.js        ビル街（配置・ビル本体・屋上設備・壁面装飾の使い回し・空）
js/shaders.js     空の色・霧・ハッシュなど共通 GLSL
js/effects.js     風の筋（粒子）とビネット
js/fall.js        落下速度のモデル（VR/PC 共通）
js/audio.js       風切り音（Web Audio 合成）
js/hud.js         VR 内の案内板
vendor/three.module.min.js   Three.js r165（MIT License）
```
